# Commands (BeatStack)

Comandos locales de Cursor para este repo. Aparecen al abrir el proyecto en Cursor.

| Command | Uso |
|---------|-----|
| `/fix` | Diagnóstico y corrección de bugs |
| `/new-feature` | Feature nuevo con plan y convenciones |
| `/refactor` | Refactor sin cambiar comportamiento |
| `/add-node-type` | Añadir un tipo de nodo al editor |
| `/post-implementation` | Checklist antes de commit/PR |
| `/ship` | Verificar, commit y PR |

Origen: adaptados desde `cursor-project-setup`, `tekae` y `labby-dabby` en `C:\Projects`.
